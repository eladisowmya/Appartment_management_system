# Apartment Visitor Management System

A simple FSD mini project using HTML, CSS, JavaScript, Node.js, Express, and MySQL.

## Features
- Add and view residents
- Register visitors
- Record visitor entry and exit
- View visitor records
- Search visitor records by resident

## Setup
1. Install Node.js and MySQL.
2. Open this project folder in VS Code.
3. In MySQL, run `database.sql`.
4. In a terminal inside this folder, run:
   `npm install`
5. Copy `.env.example` to `.env` and enter your MySQL password.
6. Run `npm start`
7. Open `http://localhost:3000`

Note: This is a student mini-project/demo. Add authentication and stronger validation before real deployment.
